# 梦镜 DreamShot 1.10.1

这是 ComfyUI 的 Ref2VA-Gates 工作台扩展包。本包包含最新工作台脚本、可导入工作流和完整扩展代码；不包含模型、素材和生成结果。

## 包内文件

- 仓库根目录（安装后为 `ComfyUI/custom_nodes/ComfyUI-DreamShot/`）：自定义节点代码。最新版工作台脚本位于：
  `web/ref2va-unified-director-studio-v190.js`。
- `workflows/DreamShot_v1.10.1.json`：可直接拖进 ComfyUI 画布的单节点工作流。
- 本教程。

## 安装

1. 先关闭 ComfyUI，或确认当前没有生成任务在执行。
2. 打开你的 ComfyUI 根目录，进入 `ComfyUI/custom_nodes/`。
3. 如果已经有旧版（例如旧名 `ComfyUI-Ref2VA-Gates` 或旧版 `ComfyUI-DreamShot`），
   建议先将旧文件夹改名为带 `-backup` 后缀的名称，以便随时回退。不要将新旧两个同名扩展
   同时放在 `custom_nodes` 目录中。
4. 通过 `git clone` 安装，或将 Release ZIP 解压后的 `ComfyUI-DreamShot` 整个文件夹放入
   `ComfyUI/custom_nodes/`。
5. 启动 ComfyUI。等待终端完成加载后，在浏览器按 `Ctrl + F5` 强制刷新页面。
6. 将 `workflows/DreamShot_v1.10.1.json` 拖到 ComfyUI 画布。看到
   `梦镜 DreamShot` 工作台即表示工作流已加载。

## 首次生成

1. 在镜头卡片或右侧“生成视频与版本”区选择要编辑的镜头。
2. 填写本镜头提示词；按需要添加图、视频、音频或首帧/尾帧素材。
3. 打开“首次生成参数”，设置分辨率、采样步数、种子和时长。
4. 不需要二采或视频放大时，保持“超分 / 多次采样 / 最终视频放大”关闭。
5. 点击“生成当前镜头”。第一次生成会完成第一采，并将原版保存进视频库的“原版视频”分组。

## 一采后只做二采、H3 超分或最终放大

适用场景：第一采已经满意，之后才决定做二采、H3 Latent 超分、NVIDIA RTX 或
TE FlashVSR，不希望浪费时间重新跑一采。

1. 在“生成视频与版本”中选择该条 **原版**。
2. 点击“基于此原版继续二采 / 放大”。
3. 工作台会展开“超分 / 多次采样 / 最终视频放大”，并自动开启二采。
4. 选择二采方式和最终放大方式，然后再次点击“生成当前镜头”。

只要主采样参数、画布和提示词没有变化，系统会复用这条一采的 latent，只执行二采、
H3 Latent 超分或视频放大。完成状态中会显示“复用原版 latent，仅执行二采/超分”。
如果你改动了上述主采样条件，系统会安全地重新第一采，避免使用不兼容缓存。

## 视频库

视频库位于“合并后的视频预览”下方，分为四组：

1. **原版视频**：第一采输出。可导出、送去二采、送去放大或删除。
2. **二采 / H3 超分视频**：完成二采或 H3 Latent 超分、尚未使用 RTX/TE 的版本。
   可导出、送去放大或删除。
3. **RTX / TE 视频放大**：已经使用 NVIDIA RTX 或 TE FlashVSR 的处理版本。
   可导出、再次送去放大或删除。
4. **合并结果**：每一次镜头合并都会留下历史成片。可播放、导出或删除。

删除视频会先要求确认；项目视频会移入项目回收区，而不是直接清除其他镜头或素材。

## 送去放大

在“原版视频”“二采 / H3 超分视频”或“RTX / TE 视频放大”卡片点击“送去放大”：

1. 页面会自动跳转并展开“已有视频放大”。
2. 选中版本会直接预载到预览区，不会被加入参考素材，也不会重新上传到 `input` 文件夹。
3. 选择 NVIDIA RTX 或 TE FlashVSR、倍率和质量参数，点击“执行已有视频放大”。
4. 结果先保留为临时结果；确认满意后，点击“导出放大后视频”才会下载。

## 合并镜头与导出

1. 在每个镜头卡片缩略图上方的“本次合并”下拉框中，为每个镜头单独选择原版或处理版。
2. 点击“合并所选”。
3. 在“合并后的视频预览”中查看当前成片和“本次合并实际使用文件”。
4. 点击“导出合并清单”，可保存本次每个镜头实际使用的文件来源。
5. 合并成片会同时进入视频库的“合并结果”，不会覆盖之前的合并记录。

## 常见问题

### 页面还是旧界面

先确认 ComfyUI 已完全重启，再在浏览器使用 `Ctrl + F5`。普通刷新可能会继续使用旧的
前端脚本缓存。

### 设置和版本预览太占空间

“镜头 N 设置”和“生成视频与版本”标题前都带有箭头。点击标题即可收起或展开：
`▶` 代表当前已收起，`▼` 代表当前已展开。右侧的“当前镜头 N”下拉框仍可直接切换镜头。

### 点击“送去放大”后没有视频

确认该版本的原始文件仍在视频库中，且没有被移入项目回收区。若选择的是原版或二采版本，
预览提示会显示“已选择项目视频”。

### 二采后又跑了第一采

复用 latent 需要一采相关参数保持一致。修改提示词、画布比例、百万像素、主采样器、步数、
调度器、降噪或主采样 Sigma 设置后，系统会重新第一采，这是为了保证结果正确。

### TE FlashVSR 不可用

确认 ComfyUI 已安装并成功加载 `TEFlashVSRModelLoader`、`TEFlashVSRTuning` 和
`TEFlashVSRRestore` 节点，以及 FlashVSR 所需模型。工作台会把未加载节点的原因直接显示在状态区域。

## 升级注意事项

- 升级前可备份旧版插件文件夹（旧名 `ComfyUI-Ref2VA-Gates`，现名 `ComfyUI-DreamShot`）和你的工作流 JSON。
- 本包不会自动删除历史项目、视频库内容或输出文件。
- 若安装后发现异常，将新扩展文件夹移出 `custom_nodes`，再把备份文件夹改回原名即可回退。
